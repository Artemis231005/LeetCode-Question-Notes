# LeetCode 18 — 4Sum

## Metadata

* **LeetCode:** 18
* **Problem:** 4Sum
* **Difficulty:** Medium
* **Topics:** Array, Two Pointers, Sorting
* **Pattern:** Sort + Fix Two Elements + Two Pointers
* **Key Technique:** Sort the array, fix the first two elements of each quadruplet via nested loops, then use two pointers on the remaining sorted range to find pairs summing to the needed remainder — skipping duplicates at every level
* **Optimal Complexity:** `O(n³)` Time, `O(1)` Auxiliary Space (excluding the output)

---

## Problem Statement

Given an integer array `nums` and an integer `target`, return all unique quadruplets `[nums[a], nums[b], nums[c], nums[d]]` (with distinct indices) such that `nums[a] + nums[b] + nums[c] + nums[d] == target`. The solution set must not contain duplicate quadruplets.

---

## Approaches

1. **Brute Force — Check Every Quadruplet with a Hash Set for Deduplication**
2. **Optimal — Sort + Fix Two Elements + Two Pointers**

---

# Approach 1 — Brute Force / Check Every Quadruplet with a Hash Set for Deduplication

## Idea

Check every possible quadruplet `(i, j, k, l)` directly. Whenever four values sum to `target`, sort that quadruplet and insert it into a hash set to automatically avoid duplicates in the final answer.

## Dry Run

```text
nums = [1, 0, -1, 0, -2, 2], target = 0
```

Check quadruplet `(1, 0, -1, 0)` (indices 0,1,2,3):

```text
1 + 0 + (-1) + 0 = 0 → valid → sorted [-1,0,0,1] → add to set
```

Check quadruplet `(1, 0, -2, 2)` (indices 0,1,4,5):

```text
1 + 0 + (-2) + 2 = 1 → not 0 → skip
```

Continue through all remaining quadruplets — valid unique ones found include `[-2,-1,1,2]`, `[-2,0,0,2]`, `[-1,0,0,1]`.

## Algorithm

1. Initialize an empty hash set of quadruplets.
2. For each `i < j < k < l` (four nested loops over all index combinations):

   * If `nums[i] + nums[j] + nums[k] + nums[l] == target`, sort the quadruplet and insert it into the set.
3. Return the set's contents as a list.

## Complexity

* **Time:** `O(n⁴)`

  * Four nested loops check every possible quadruplet directly.
* **Space:** `O(n)` (beyond the output)

  * For the hash set used to deduplicate quadruplets.

## Notes / Tips

* Checking every quadruplet is the most naive approach possible — sorting the array first (as in Approach 2) both speeds up the search and makes duplicate-skipping far simpler and cheaper than hashing entire quadruplets, exactly as with LC 15 (3Sum) extended one dimension further.
* Integer overflow is a real risk here: summing four `int` values (each potentially near `INT_MIN`/`INT_MAX`) can overflow a 32-bit `int`; using a wider type for the running sum avoids silent incorrect comparisons.

## Code

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        int n = nums.size();
        set<vector<int>> uniqueQuads;

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                for (int k = j + 1; k < n; k++) {
                    for (int l = k + 1; l < n; l++) {
                        long long sum = (long long)nums[i] + nums[j] + nums[k] + nums[l];
                        if (sum == target) {
                            vector<int> quad = {nums[i], nums[j], nums[k], nums[l]};
                            sort(quad.begin(), quad.end());
                            uniqueQuads.insert(quad);
                        }
                    }
                }
            }
        }

        return vector<vector<int>>(uniqueQuads.begin(), uniqueQuads.end());
    }
};
```

# Approach 2 — Optimal / Sort + Fix Two Elements + Two Pointers

## Idea

Sort the array first. Fix the first two elements of a candidate quadruplet with two nested loops (`i` and `j`), then use two pointers (`left` starting right after `j`, `right` at the end) to search the remaining sorted range for a pair summing to `target - nums[i] - nums[j]` — moving `left` right or `right` left based on whether the current sum is too small or too large. Skip over duplicate values at every level (`i`, `j`, `left`, `right`) to avoid duplicate quadruplets without needing a hash set.

## Dry Run

```text
nums = [-2, -1, 0, 0, 1, 2]  (already sorted), target = 0
```

`i = 0` (value `-2`):

```text
  j = 1 (value -1), need pair sum = 0-(-2)-(-1) = 3
    left=2 (0), right=5 (2): sum=0+2=2 < 3 → left++
    left=3 (0), right=5 (2): sum=0+2=2 < 3 → left++
    left=4 (1), right=5 (2): sum=1+2=3 == 3 → found [-2,-1,1,2]
      skip duplicates, move left++, right-- → left=5, right=4 → stop

  j = 2 (value 0), need pair sum = 0-(-2)-0 = 2
    left=3 (0), right=5 (2): sum=0+2=2 == 2 → found [-2,0,0,2]
      move left++, right-- → left=4, right=4 → stop

  j = 3 (value 0): same as nums[2]=0 → skip (duplicate second element)

  j = 4 (value 1), need pair sum = 0-(-2)-1 = -3
    left=5, right=5: left==right → no pairs to check
```

`i = 1` (value `-1`):

```text
  j = 2 (value 0), need pair sum = 0-(-1)-0 = 1
    left=3 (0), right=5 (2): sum=0+2=2 > 1 → right--
    left=3 (0), right=4 (1): sum=0+1=1 == 1 → found [-1,0,0,1]
      move left++, right-- → left=4, right=3 → stop
```

Continuing similarly (skipping further duplicates) yields no additional quadruplets.

Final unique quadruplets: `[-2,-1,1,2], [-2,0,0,2], [-1,0,0,1]`.

## Algorithm

1. Sort `nums` in ascending order.
2. For each `i` from `0` to `n-4`:

   * If `i > 0` and `nums[i] == nums[i-1]`, skip (avoids duplicate first elements).
   * For each `j` from `i+1` to `n-3`:

     * If `j > i+1` and `nums[j] == nums[j-1]`, skip (avoids duplicate second elements).
     * Set `left = j + 1`, `right = n - 1`.
     * While `left < right`:

       * `sum = nums[i] + nums[j] + nums[left] + nums[right]` (using a wide type to avoid overflow).
       * If `sum == target`: record the quadruplet, then skip duplicates by advancing `left` while `nums[left] == nums[left+1]` and `right` while `nums[right] == nums[right-1]`, then move both pointers inward once more.
       * If `sum < target`: increment `left`.
       * If `sum > target`: decrement `right`.
3. Return the list of quadruplets found.

## Complexity

* **Time:** `O(n³)`

  * Sorting is `O(n log n)`; the two outer loops together run `O(n²)` times, and each iteration's two-pointer scan is `O(n)`.
* **Space:** `O(1)` auxiliary (beyond the output and sort's own space)

  * No hash set needed — duplicate avoidance is done directly through sorted-array skipping.

## Notes / Tips

* This is a direct extension of LC 15's (3Sum) sort + fix-elements + two-pointers skeleton, adding one more fixed loop (`j`) before the two-pointer scan — the same core technique scales to "k-sum" for any `k`, fixing `k-2` elements via nested loops and finishing the last two with two pointers.
* Using a `long long` (or equivalent wide type) for the running sum is important here aswith four values summed together, overflow of a 32-bit `int` is a genuine risk depending on `nums`' value range.
* Duplicate-skipping is needed at **all four** levels (`i`, `j`, `left`, `right`) — skipping it at any one level can produce duplicate quadruplets in the output, since each level independently controls one "slot" of the quadruplet.

## Code

```cpp
class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> result;
        int n = nums.size();

        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;

            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;

                int left = j + 1, right = n - 1;

                while (left < right) {
                    long long sum = (long long)nums[i] + nums[j] + nums[left] + nums[right];

                    if (sum == target) {
                        result.push_back({nums[i], nums[j], nums[left], nums[right]});

                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (left < right && nums[right] == nums[right - 1]) right--;

                        left++;
                        right--;
                    } else if (sum < target) {
                        left++;
                    } else {
                        right--;
                    }
                }
            }
        }

        return result;
    }
};
```
