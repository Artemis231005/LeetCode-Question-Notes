# LeetCode Question Notes

This repository contains my **LeetCode problem notes** while practicing **Data Structures and Algorithms (DSA) in C++**.

The notes are maintained primarily for **personal reference, revision, and tracking problem-solving patterns** across different types of LeetCode problems.

## Why This Repository Exists

I created this repository to:

* Keep a structured record of the **LeetCode problems I practice**.
* Revisit different **approaches and problem-solving patterns** during revision.
* Understand the progression from **brute-force to optimized solutions**.
* Keep explanations, dry runs, complexities, and implementations together for easy reference.
* Strengthen my problem-solving skills through consistent practice.

## Structure

* Problems are organized into folders based on their **LeetCode question number range**.
* Each problem has its own Markdown file.
* Files are named using the **question number and problem name**.

Example:

```text
LeetCode-Notes/
├── 0001-0050/
│   ├── 0001_Two Sum.md
│   └── ...
├── 0051-0100/
│   ├── 0056_Merge Intervals.md
│   ├── 0100_Same Tree.md
│   └── ...
├── 0101-0150/
│   ├── 0135_Candy.md
│   └── ...
└── README.md
```

Each problem note contains:
* Problem statement
* Key observations
* Multiple approaches
* Explanation of the approach
* Dry run
* C++ implementation
* Time and space complexity
* Important edge cases and implementation details

## Metadata & Searchability

Each problem note includes **structured metadata** such as:

* **Question Number**
* **Problem Name**
* **Topic**
* **Difficulty**
* Other relevant problem tags

This metadata makes the repository **searchable and easy to filter**, allowing problems to be found not only by their question number or name, but also by concepts such as **Greedy, Binary Search, Sliding Window, Trees, Bit Manipulation**, etc.
